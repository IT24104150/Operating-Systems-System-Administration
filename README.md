# Operating Systems & System Administration 🖥️⚙️

Welcome to my repository dedicated to **Operating Systems (OS) and System Administration**. This repository serves as a centralized hub for my laboratory practicals, configuration scripts, and theoretical implementations developed during my 2nd year as a Computer Systems and Network Engineering undergraduate at SLIIT.

The core focus of this module/project is understanding how operating systems manage hardware resources, execute processes, and how to effectively administer, secure, and automate multi-user enterprise environments.

---

## 📌 Core Objectives
* **OS Internals:** Understanding process scheduling, memory management, file systems, and concurrency.
* **System Administration:** Hands-on experience with Linux/Windows server administration, user management, and security policies.
* **Automation:** Writing robust Bash, Python, and PowerShell scripts to automate routine administrative tasks.
* **Network Services:** Configuring and managing critical infrastructure services like DHCP, DNS, SSH, and FTP.
